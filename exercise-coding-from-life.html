Exercise: CSS Drawing (Oct 13)

Go to the University Center library and find yourself a spot with a nice view. Using your knowledge of HTML and CSS, draw what you see in your browser window.

For inspiration, see Juliet Brown's Creative Coding: Learning to Draw with CSS and Diana Smith's Pure CSS Vignes.

Some useful CSS tricks for shapes: The Shapes of CSS. For more helpful CSS properties, see the CSS toolbox for the drawing exercise.
