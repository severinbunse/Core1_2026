Exercise: Coding from Life

We will stage a still life in class. Draw it on a webpage using only HTML and CSS: no images, no SVG, no JavaScript. Look closely at the objects in front of you, then work out how to build each shape, color and shadow with code.

To get started, you can use this starter kit.

Resources: Shapes of CSS, Simpsons in CSS, CSSmatic

Drawings from earlier classes: 2015, 2018

This exercise is based on Coding from Life by Laurel Schwulst.
