Project 1: Choose One (Sep 1 – Sep 15)

1a — Journal a walk or field trip: Walk around somewhere and observe the environment around you. Bring along a journal or notetaking app. You could document people, plants, places you see along the way, for example. Turn this walk into a webpage by writing HTML. You should use a variety of tags to express your ideas.

1b — Document an interview: Conduct an interview with someone about a subject of your choosing. Record this interview and turn it into a webpage by writing HTML. You should use a variety of tags to express your ideas.

You will learn: HTML structure and semantic tags, Documenting content through markup, Site navigation

Part 1 — Semantics and Styles (Weeks 1–5)

The first segment of Core Interaction will focus on the environment and semantics required for building interactive experiences. We use the web as a starting point for students to understand what a screen-based interactive experience is, and what the opportunities are there for designers to intervene.

Project 2: Recipe (Sep 15 – Sep 29)

A recipe is a set of instructions to achieve a standardized result. A recipe is most typically thought of in a cooking context, but an algorithm is also a recipe. Create your own "recipe" in HTML. Then, have 2 other people make your recipe and document the results on the same webpage. You must use <img>, <a>, <section>, <p> at least once.

You will learn: Structuring instructions as markup, Working with images and links, Documenting outcomes from other users

Project 3: Choose One (Sep 29 – Oct 20)

3a — Museum painting recreation: Find a museum that would allow you to open your laptop while observing an artwork. (Note — if this is truly not possible, go to a museum and take a photo of an artwork for later). Re-draw this painting on a webpage using CSS.

3b — Visual-only webpage: Create a webpage that exists only for visual contemplation. It cannot have any usable functions nor serve a utilitarian purpose.

You will learn: CSS positioning and values, Recreating visual composition with code, Layout constraints as a design tool

Part 2 — Structures and Patterns (Weeks 5–11)

In our second segment, we'll investigate how designing for the digital canvas differs from other media. We will aim to understand the inherent complexities and how to use them to create compelling digital experiences.

Project 4: Collective Web Zine (Oct 27 – Nov 10)

A zine is a small, self-published booklet or magazine. It is usually made by one person or a group. Your class will be creating its own web zine. As a class, create ideas for a collection centered around one theme. Then, use HTML and CSS to create your own "page" for the zine. Then, link all of your pages together to create a website.

You will learn: Collaborative HTML/CSS workflow, Linking multi-page sites, Shared visual systems

Project 5: Clock with JS (Nov 10 – Nov 24)

We provide the clock framework using setInterval. You have the chance to make it do something different depending on the time of day, using style, if/else, and so on.

You will learn: JavaScript variables and conditionals, setInterval and timing, Updating the DOM over time

Part 3 — Experiences and Tools (Weeks 11–15)

As we begin to develop systematic thinking through HTML and CSS practice, JavaScript will be introduced in our final segment for ideas of programming and automation. We will use web-based JavaScript to write functions and tools for ourselves and other audiences to use and play with.

Project 6: Choose One (Nov 24 – Dec 1)

6a — Instrument: Using events and interactions, create your own instrument. You can either make this instrument using clicks on screen, or with keyboard events.

6b — Alternate keyboard: Make a keyboard for something other than typing — use mouse movement or key presses to interact.

You will learn: Event listeners (mouse and keyboard), Creating and appending DOM elements, Mapping input to sound or interaction

Project 7: Daily Tool Website (Dec 1 – Dec 8)

Now that you know HTML, CSS, and JS, you have all the capabilities to create a web application. Using this knowledge, create a tool that you could use daily that lives on a webpage.

You will learn: Full HTML/CSS/JS integration, Designing a personal tool, DOM manipulation at scale
