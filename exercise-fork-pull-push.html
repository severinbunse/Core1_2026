In-Class Exercise: Fork, Commit & Pull Request (Sep 29, 2026)

This page is going to become a shared design project. The HTML stays the same for everyone, but each of you will write your own stylesheet for it. Soon, anyone visiting the site will be able to switch between your versions.

To add your stylesheet, you'll use the same workflow designers and developers use to contribute to projects they don't own:

  1. Fork: make your own copy of the class repository on GitHub: github.com/severinbunse/Core1_2026
  2. Clone: download your fork to your computer and open it in VS Code.
  3. Style: in the themes folder, open the file with your first name, for example themes/kitty.css. It already lists every class and ID on this page, so you can focus on styling. To see your changes, open this page in your browser and add ?theme=kitty (with your name) to the end of the address. Change only your own file: no HTML, and no one else's CSS.
  4. Push: commit your changes and push them to your fork.
  5. Pull request: on GitHub, open a pull request from your fork to the class repository. I'll review it and merge it into the site.

Share the link to your pull request when you're done.
