Exercise: Commit to Diary (Oct 20)

Using what you've learned about cloning, committing and pushing with GitHub Desktop, you'll keep a live diary of a place.

Find a busy spot around school, like a lobby, hallway, elevator bank or café, and settle in. Every 3–5 minutes, write down what you see and/or hear, then commit and push it. Keep going until 11:40. Aim for at least 16 entries.

Each push goes live on your own diary and on the class diary, where everyone's entries come together in order of time.

Step by step

Set up

  1. On the template, click Use this template. Name your repository commit-to-diary and keep it Public. Unlike a fork, this is your own repository, not linked to the template, so there's no pull request.
  2. Under Settings → Pages, choose main and Save.
  3. In GitHub Desktop, choose File → Clone Repository, select commit-to-diary and click Clone.
  4. Click Open in Visual Studio Code.

Every 3–5 minutes

  1. Copy an entry in index.html, paste it below the last one, and write.
  2. Save.
  3. In GitHub Desktop, sum up your entry in a few words, e.g. door keeps slamming, and click Commit to main.
  4. Click Push origin.
