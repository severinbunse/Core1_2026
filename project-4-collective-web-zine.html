Project 4: Collective Web Zine (Due Nov 10)

A zine is a small, self-published booklet or magazine. It is usually made by one person or a group. Your class will be creating its own web zine. As a class, create ideas for a collection centered around one theme. Then, use HTML and CSS to create your own "page" for the zine. Then, link all of your pages together to create a website.

The class selected the following themes: "Everyone makes a page dedicated to their musical artist of choice, the page can be decorated to the style of said artist, including facts about them, most famous songs, etc."
